A one-line joke about working beside an AI coding agent that reviews
code and approves pull requests, built for the
[make.fun bounty](https://make.fun/bounty/the-joke-the-reviewer-laughs-at-20261121-0329).

## Run

```sh
python3 main.py
```

It writes exactly one joke to `/output/entry.txt` (1–280 characters,
no network).
